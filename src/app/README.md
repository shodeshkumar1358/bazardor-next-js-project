বাজার দর — BazarDor

BazarDor is a modern Bengali market-price application that helps users easily check the latest prices of daily essential products.

# ✨ Features

🛍️ View daily prices of essential products
📈 See products with increasing and decreasing prices
🔎 Browse products by category with price sorting
📊 View detailed market-based product prices
🔐 Secure authentication with Better Auth
👤 User profile and profile update
🔔 Toast notifications for user actions
⏳ Loading skeletons and custom 404 page
📱 Fully responsive for mobile, tablet, and desktop
🔢 Bengali numeral price sorting
